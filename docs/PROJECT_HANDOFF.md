## 4. 本轮新增功能与用户已确认决定

1. 增加背景并重制图标，延续现代、扁平、圆角和清晰手柄焦点。历史候选只重绘 VR 快捷面板（深色渐层、轻微青紫光和线性图标），不要描述成全应用视觉重制完成；主界面现有壁纸功能保留。
2. 删除串流菜单中调出手机软键盘的选项，移除应用内置 View 键盘。只禁用 Android IME 不会阻止 View 键盘，二者单独核对。
3. 用户原话：VR 中关闭所有本机输入法入口。覆盖菜单、快捷轮盘、快捷动作/悬浮入口、多指手势、远端文本框自动弹出、设置/对话框文本控件、活动/弹窗窗口状态和进入 VR 前已显示输入法；退出 VR 恢复原窗口行为。
4. 实体键盘/鼠标/手柄输入仍转发至电脑。电脑端屏幕键盘是远端快捷操作，保留，不与手机输入法混淆。
5. 用户原话：允许跳转并接受普通 2D 页面。系统文件选择器、Android 设置、外部浏览器是明确兼容例外，不拦截、不擅自删除；回到应用仍需恢复 VR、方向和输入。
6. 用户在解释 Toast 后确认：VR 模式下隐藏 Toast。适用于应用产生的临时 Android 提示条；普通 2D 模式保持提示。不要把错误对话框/加载状态等也一并隐藏。
7. 其他应用内部页面或弹窗若确定会跳出 VR/冲突且需要删功能或改适配方案，先列出具体位置、现象与影响让用户决定；不要因普通 2D 布局就判断冲突，多数会被捕获进立体场景。
